# STORY MODE — 게임 사이트

`20241754_김민솔` 사이트와 따로 실행되는 턴제 RPG 게임 사이트입니다. 빌드 도구나 라이브러리 없이, 기존 사이트처럼 정적인 HTML/CSS/JS로 만들었습니다.

## 실행 방법

| 방법 | 하는 법 | 주소 |
|---|---|---|
| 그냥 열기 | `바탕화면/20241754_김민솔/index.html` 더블클릭 → 메인 화면 **스토리 모드** | `file://` |
| 게임만 열기 | `게임 구현/game-site/index.html` 더블클릭 | `file://` |
| 개발 서버 | `게임 구현/start-dev.bat` 더블클릭 (Node.js 또는 Python 필요) | 기존 사이트 `localhost:5500` / 게임 `localhost:5501` |

- 게임 왼쪽 위 **LOBBY** 버튼을 누르면 들어왔던 기존 사이트로 돌아갑니다.
- VS Code Live Server처럼 다른 포트를 쓰면 `20241754_김민솔/js/game-link.js`의 `GAME_URL.dev`와 `game-site/js/main.js`의 `LOBBY_DEV_URL`을 그 주소로 맞춰 주세요.

## 두 사이트의 연결 구조

```
바탕화면/
├─ 20241754_김민솔/          기존 사이트 (변경: js/game-link.js 추가 + index.html에 script 한 줄)
└─ 게임 구현/
   ├─ start-dev.bat · dev-server.js   두 사이트 동시 실행 (5500 / 5501)
   └─ game-site/              게임 사이트 (독립 실행)
```

- 기존 사이트 → 게임: 스토리 모드 버튼이 `game-site/index.html?return=<로비 주소>`로 이동합니다.
- 게임 → 기존 사이트: `?return` 주소로 돌아가며, 주소가 없으면 실행 방식에 맞는 기본 주소를 씁니다.
- 공유 데이터: 캐릭터는 기존 `CHARACTER_DATABASE`의 **id**(`Character_05` 등)를 같은 키로 씁니다. 게임에 필요한 이미지는 `assets/characters/<id>/`에 용량을 줄여 복사해 두었습니다(원본 약 2MB → 약 85KB). 두 사이트는 서로의 파일을 불러오지 않기 때문에 한쪽의 렌더링이 다른 쪽에 영향을 주지 않습니다.
- 진행 상황은 브라우저 localStorage `AGENT_GAME_SAVE`에 저장됩니다. 저장 내용이 손상됐거나 버전이 다르면 자동으로 초기화됩니다.

## 화면 흐름

챕터(비디오 테이프) → 챕터 맵(열린 스테이지만 표시) → 스테이지 팝업(이름 · 설명 · 입장) → 검은 화면 + 스테이지 이름 3초 → 대사(클릭 / SKIP) → 편성 → 전투 → 승리하면 스테이지 화면으로 돌아오고 다음 스테이지가 열림

| 챕터 1 스테이지 | 내용 | 열리는 조건 |
|---|---|---|
| STAGE 01 | 튜토리얼 전투 (3턴 이내) | 처음부터 |
| STAGE 02 — 실습은 계속된다 | 스토리 전용 (SCENE 01~03) | STAGE 01 클리어 |
| STAGE 03 | 스토리 전용 (SCENE 01~03, 끝나면 STAGE CLEAR) | STAGE 02 완료 |
| STAGE 04 — 실력 검증 | 스토리(SCENE 01) → 4명 고정 편성 → 교사와 전투 → 승리 후 스토리(SCENE 02 기대되는 팀) | STAGE 03 완료 |
| STAGE 05 | 임시 전투 스테이지 | STAGE 04 전투 후 스토리까지 완료 |

- CHAPTER 02~05 는 아직 잠겨 있습니다(회색 · 클릭 불가).
- 스토리 전용 스테이지는 편성/전투 없이 스토리가 끝나면(또는 SKIP하면) **STAGE CLEAR** 후 클리어 처리됩니다.
- 장면(SCENE)이 바뀔 때 검은 화면에 장면 번호 · 제목 · 장소가 표시되며, 클릭하면 바로 넘어갑니다.
- 열리는 조건은 `js/data/chapters.js`의 `requires` 값으로 바꿀 수 있습니다. 챕터를 열 때는 챕터의 `available: true`와 `requires`(선행 스테이지)를 지정합니다.

## 번개 (레이 · 코루스코)

- 레이나 코루스코가 편성되면 화면 오른쪽에 **번개 아이콘과 숫자**(파티 공유 [번개] 스택)가 표시됩니다. 20 이상이면 금색으로 바뀝니다.
- [번개]가 쌓이는 경우
  - 아군 스킬이 [찌릿]을 부여할 때 +1 (스킬 1회당), [찌릿] 피해가 발동(반응)할 때 적 1명당 +1
  - 번개 속성 아군이 스킬을 쓸 때, 출전 중인 레이 · 코루스코 1명당 +1
  - 코루스코가 공격을 명중시킬 때 +1, [과전압 예열] 중 번개 속성 아군이 공격할 때 +2
  - 스킬 자체 수급: 과충전 포격([찌릿] 상태 적 1명당 +2), 체인 라이트닝(+2, 번개 속성 파티원 1명당 +1), 전하 플러그(예열 시 대상 [찌릿] 1스택당 +1), 뇌운의 과부하(+10)
- [찌릿]: 스택당 받는 모든 피해 +3%(최대 10스택), 턴 종료 시 지속 피해.
- 과전류 장전(번개 10)·과전압 예열(번개 10)은 [번개]가 모자라면 사용되지 않고 마법에 남습니다(카드에 '번개 부족' 표시).
- 과전류 장전을 쓴 턴에는 레이의 다른 공격 카드·궁극기가 사용되지 않고 마법에 남으며, 효과는 다음 턴에 적용됩니다.
- 과전압 예열은 [번개] 10을 써서 **3턴** 동안 유지됩니다(쓴 턴부터 적용 → 같은 턴 뒤쪽 슬롯의 체인 라이트닝·전하 플러그부터 강화). 체인 라이트닝 90% → 280%(적 전체), 전하 플러그 110% → 350%.
- 코루스코가 필드에 있으면 **첫 턴 마법에 과전압 예열 카드가 반드시 나옵니다**(시작 [번개] 10 → 바로 사용 가능).
- 궁극기 [EMS]: 명중한 적의 일반 스킬 1개를 3턴 동안 봉인합니다. (문서의 'EMS 2턴'과 '봉인 3턴' 중 봉인 3턴으로 통일 — 임시)
- 밸런스 영향(시뮬레이션): 코루스코가 들어간 덱의 STAGE 05 중간 보스 처치가 평균 약 5턴 → 4.5턴으로 빨라짐. STAGE 08 보스(같은 스킬 사용)의 스토리 덱 클리어율은 변화 없음(약 67%).
- [EMS]: 적의 일반 스킬 1개를 무작위로 3턴 봉인합니다. 일반 스킬이 하나뿐인 적(검은 실루엣)은 그동안 궁극기 외에는 행동하지 못합니다.
- 뇌신 붕괴포는 [번개] 1개당 피해 계수 +12%p(예: 20개 → 350% + 240%)이며, 발동 후 [번개]는 0이 됩니다.

- 예열 카드(과전류 장전 · 과전압 예열)는 다른 카드보다 조금 덜 나오고(뽑힐 확률 0.6배), 캐릭터마다 마법에 1장까지만 있습니다.
- 예열 · 분신 · EMS 상태는 머리 위에 **이름 + 남은 턴** 칩으로 표시됩니다. 과전류 예열은 쓴 턴에는 '과전류 다음 턴'(점선), 다음 턴부터 '과전류 1턴'으로 바뀌며 빛납니다.

## STAGE 05 — 중간 보스 (임시)

- 캐릭터 성능 확인용 스테이지입니다. 중간 보스는 덱(캐릭터 선택) 목록에 들어가지 않습니다. 이름이 정해지지 않아 '중간 보스'로 표시하고, 스프라이트도 따로 만들 예정이라 지금은 푸른 실루엣(일반 적보다 큼)입니다.
- 스킬: 수류 도트 사격(180% + [물방울 침식] 3턴) → 물의 분신 회피(공격 1회 무효화) → 자연의 축복수(자기 진영 공격력 +20% 2턴 · 공격력 100% 회복) 순서로 쓰고, **4번째 행동마다** 궁극기 해일의 거대 용(전체 360% + 5턴간 [비]).
- [비]: 물 속성 기술 공격력 +30%(보스와 샤린 모두), 아군 화염 속성 기술 공격력 −40%(아르덴 · 알리제의 화염 스킬). 비가 내리는 동안 전장에 빗줄기가 보입니다.
- 밸런스(오토 전투 40회 시뮬레이션): 아르덴 · 샤린 · 나즈나 · 알리제 40/40 승 · 평균 11턴, 레이 · 코루스코 · 아르덴 · 샤린 40/40 승 · 평균 6턴, 3명 편성은 대체로 패배.

## STAGE 06 ~ 08

- STAGE 06 · 07: 임시 스테이지(검은 실루엣 2명 · 3명, 자유 편성).
- STAGE 08 — 메인 보스전 (적: 코루스코)
  - 스토리 편성 고정: 알리제 · 나즈나 · 샤린 출전, 아르덴 대기. 스토리 텍스트는 아직 없어 바로 편성 화면으로 들어갑니다.
  - 코루스코는 플레이어용과 같은 스킬 3개 · 궁극기를 쓰며, 적 진영의 [번개]는 내부에서만 셈합니다(화면에 표시하지 않음 · 시작 10).
  - 궁극기 포인트 4: 행동할 때마다 1씩 쌓이고(머리 위 ◆), 가득 차면 다음 행동이 궁극기(EMS로 아군 스킬 1개 3턴 봉인 · [찌릿] · 뇌운 지대).
  - 행동 순서: 체인 라이트닝 → 과전압 예열 → 전하 플러그(예열 강화) → 반복. 적은 한 턴에 한 번 행동하므로 과전압 예열이 다음 행동까지 유지됩니다.
  - **연출된 결말**: 코루스코의 체력은 5% 아래로 내려가지 않습니다. 그 순간 → 왼쪽 위 코루스코 초상화 "헛수고하지 말고 가만히 있어." → 결말 공격(컷인 + 낙뢰)으로 아군 전원(대기석 포함) 기절 → 아르덴 초상화 "으윽..." → **STAGE CLEAR**. 대사는 클릭으로 넘깁니다. 이 스테이지에만 적용됩니다(`chapters.js`의 `finale.before / after`).
  - 난이도(스토리 편성 · 오토 전투 60회 시뮬레이션): 약 67% 클리어 · 평균 9턴 (산소 폭발 변경 후 다시 맞춤). 직접 플레이하면 대상 지정 · 교체로 더 유리합니다.
- 아군 스킬이 EMS로 봉인되면 그 카드에 'EMS 봉인'이 표시되고, 써도 사용되지 않고 마법에 남습니다(봉인된 스킬은 새로 뽑히지 않음).

## 스토리 편성 스테이지 다시 하기

- 고정 편성 스테이지(1 · 4 · 8)는 **처음 플레이할 때만** 스토리 편성으로 고정됩니다.
- 처음 플레이할 때도 편성 칸을 누르면 캐릭터 목록과 설명(스탯 · 속성 · 스킬)을 볼 수 있습니다. 변경 버튼 대신 **'스토리에서는 캐릭터를 변경할 수 없습니다'** 안내와 닫기 버튼이 나옵니다.
- 클리어한 뒤 다시 하면 편성을 자유롭게 바꿀 수 있고, 왼쪽의 **스토리 덱으로 플레이** 버튼을 누르면 스토리 편성이 자동으로 채워집니다(그 뒤에도 수정 가능).

## 페델레 · 치유사

- **페델레**: 중압의 일격(140% + [부담감] 1) · 절대 역장(보호막 + 디버프 1개 해제 + 피해 감면 30%, 2턴) · 중력 파열(적 2명 110% + [부담감] 1, 이미 [부담감]이던 적은 1턴 [행동 제어]) · 그랜드 프레셔(전체 220% + [부담감] 1스택당 +10% · [부담감] 2 · 2턴간 피해 감면 50%).
  - [부담감]: 스택당 공격력 · 방어력 −5% (최대 3스택). [행동 제어]: 그 턴 행동 불가(머리 위 예고가 '행동 제어'로 바뀜).
- **실반**: 신경망 연결(3턴간 받은 피해의 50%를 필드 아군에게 분산 + 받는 피해 −50% + 치유량 +20% / 대신 2턴간 [고립]으로 스킬 사용 불가) · 세포벽 정화(최대 체력 20% 보호막 + 지속 피해 −60% + 디버프 지속 −1턴) · 생명의 순환(최대 체력 25% 회복 + 자신 제외 아군 마력 70% 회복 + 3턴간 치유량 +50%, 마력 30 소모) · 세계수의 영역(2턴간 턴 종료 시 30% 회복 · 디버프 전부 해제 · 세포벽 정화 재부여 · 자신 마력 60% 회복).
- 피해 감면(절대 역장 30% · 그랜드 프레셔 50% · 신경망 연결 50%)은 서로 **중첩되지 않고 가장 큰 것만** 적용됩니다.

## 스킬 카드 그림 (모든 캐릭터)

- 모든 캐릭터의 스킬 카드가 스킬마다 다른 그림을 씁니다(`assets/characters/<id>/skill_*.svg`, 직접 만든 임시 그림). 캐릭터마다 색이 다르고, 카드 오른쪽에 이름(ARDEN · SHARIN · …)이 세로로, 아래에 약자(AR · SH · NA · AL · R · C · FE · SY)가 들어갑니다.
- 편성 화면 캐릭터 정보의 SKILL 칸에도 같은 그림이 나옵니다.
- 그림을 바꾸려면 스킬 데이터의 `art` 경로만 바꾸면 됩니다(다른 캐릭터도 `art`를 넣으면 같은 방식으로 적용).

## 속성 · 골드 패시브 [빛]

- **[마력 분배] 카드**: 골드 속성 캐릭터에게 턴마다 20% 확률로 생성. 마법 **맨 앞**에 고정되고 마법 칸을 차지하지 않으며, 턴이 시작될 때(아군 행동 전) 자동으로 사용되어 자신의 마력을 필드 아군 전체에 균등하게 나눕니다(가득 찬 아군의 남는 몫은 되돌아옴).

## 보호막 표시 · 실반의 [고립]

- 실반이 [고립] 상태인 동안에는 실반의 카드(궁극기 포함)가 마법에서 **아예 사라지고** 새로 나오지도 않습니다. 고립이 끝나면 다시 나옵니다(열의가 가득이면 궁극기 카드도 다시 생김).

## 카드 뽑기

- 필드에 있는 캐릭터는 **항상 1장 이상** 카드가 마법에 있습니다(마법가 가득 차 있으면 가장 많은 캐릭터의 카드 1장을 교체).
- 나머지 카드는 마법에 카드가 적은 캐릭터부터 골고루 채워져, 한 캐릭터의 카드만 몰리지 않습니다.

- 궁극기가 있는 적은 정해진 행동 횟수마다 궁극기를 쓰며, 머리 위 행동 예고가 금색으로 표시됩니다.

## 전투 규칙

- **1턴** = ① 아군의 모든 공격(행동 슬롯 순서) → ② 적군의 모든 공격 → ③ 턴 종료(연소 피해 → 버프·디버프·필드 지속 턴 감소 → 대기석 회복)
- 행동 슬롯은 편성 인원 수만큼만 표시됩니다(1명 1칸 ~ 4명 4칸). 스테이지 1은 1칸입니다.
- 마법 상한: 1명 2장 · 2명 3장 · 3명 4장 · 4명 6장. 카드는 출전 중인 캐릭터의 스킬 3개(궁극기 제외) 중 무작위로 나오며, **카드 등급(★)은 없습니다**.
- 카드를 누르면 슬롯에 올라가고, 슬롯의 카드를 누르면 원래 자리로 돌아갑니다. 슬롯이 다 차면 행동을 시작합니다.
- 적을 누르면 공격 대상이 바뀝니다. 사용한 카드는 사라지고, 쓰지 않은 카드는 다음 턴에도 남습니다.
- 카드를 쓸 때마다 열의(◆)가 1씩 쌓이고, 캐릭터별 필요 열의(기본 5, 레이 6, 코루스코 7)가 차면 궁극기 카드가 생깁니다.
- 출전은 3명까지이고 4번째 칸은 대기석입니다. 대기석 캐릭터는 매 턴 체력을 5% 회복합니다. 쓰러진 캐릭터 처리는 아래 '기절 · 게임 오버' 참고.
- 왼쪽 아래 **캐릭터 변경** 버튼으로 출전 캐릭터와 대기석 캐릭터를 바꿀 수 있습니다. 한 턴을 소모하며(공격 없이 적의 공격을 받음), 빠진 캐릭터의 카드는 마법에서 사라집니다.
- 버프·디버프·필드 아이콘과 카드에 마우스를 올리면 자세한 설명이 나옵니다. 오른쪽 위에서 2배속, 오토, 메뉴를 쓸 수 있습니다.
- 오토: 궁극기 → 버프·디버프 카드 → 공격 카드 순으로 사용합니다.
- 스킬을 쓰면 카메라가 시전자에게 살짝 줌인한 뒤 대상 쪽으로 따라가고, 행동이 끝나면 원래 위치로 돌아옵니다.
- 카드를 고르면 마법의 카드가 짧게 들렸다가 흐려지며 작은 순번이 표시되고, 슬롯에는 카드가 부드럽게 옮겨 갑니다(반짝임 없음).
- 이미 해금된 스테이지·챕터는 다시 클리어해도 '해금' 문구가 나오지 않습니다.
- STAGE 04의 '후속 스토리' 버튼은 클리어하고 후속 스토리까지 본 뒤 다시 열었을 때만 표시됩니다.
- 진행 속도는 `js/screens/battle-ui.js` 맨 위의 `PACE` 값(밀리초)으로 조절합니다. 값을 키울수록 느려집니다.
